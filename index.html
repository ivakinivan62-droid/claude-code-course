Бесплатный курс: основы

Коротко обо всём. Подробности, шаблоны и готовые конфиги в продвинутом курсе.

1. Что такое Claude Code

Агент для программирования от Anthropic. Вы описываете задачу обычным языком, он изучает проект, предлагает изменения и вносит их с вашего разрешения.

2. Установка и первый запуск
  1. Заведите аккаунт Claude (подписка) или получите ключ API.
  2. Установите по инструкции на docs.claude.com. Один из способов:
npm install -g @anthropic-ai/claude-code
  1. В папке проекта введите claude и войдите в аккаунт.
3. Как ставить задачи

Конкретно: что сделать, где, как проверить. Плохо: «исправь баг». Хорошо: «Кнопка «Купить» на /cart не реагирует. Найди причину, исправь, запусти тесты».

Для сложного сначала просите изучить и предложить план.

4. Режимы работы

Shift+Tab переключает режимы. Обычный спрашивает разрешение. Accept Edits сам принимает правки файлов. Plan Mode только исследует и предлагает план.

5. CLAUDE.md, память проекта

Файл в корне проекта с правилами: команды запуска, стиль, запреты. Claude читает его при каждом старте. Команда /init создаёт заготовку.

6. Главные команды

/help список. /clear новая тема. /compact сжать историю. /model выбор модели. /memory правка CLAUDE.md. /mcp сервисы. /agents субагенты. /hooks автодействия.

7. Что дальше: MCP, субагенты, хуки

MCP подключает внешние сервисы. Субагенты это узкие помощники вроде ревьюера. Хуки запускают ваши команды в нужный момент. Настройка есть в продвинутом курсе.

8. Безопасность

Не давайте доступ к боевым ключам и базам без нужды, читайте команды перед разрешением и работайте в git, чтобы всё можно было откатить.

Какая модель для чего

Список на момент публикации. Актуальные модели смотрите в /model и на docs.claude.com.

Haiku 5.5Быстрые и дешёвые задачи: переименования, мелкие правки, простые вопросы.
Sonnet 5.5Основная модель для повседневной разработки, баланс скорости и качества.
Opus 5.5Сложные задачи: архитектура, трудные баги, большие рефакторинги.
Fable 5.1Самый мощный публичный класс для самых трудных задач, с дополнительными ограничениями безопасности.

Правило: начните с Sonnet, берите Opus, когда задача сложная, и Haiku, когда важны скорость и цена.
